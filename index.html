One program, three stacks

The domains change. The discipline does not.

Inside a model, evidence can conflict. In an assay, measurements can be contaminated or structurally incomplete. At a security boundary, later instructions can claim authority they do not have. I use deterministic oracles, interventions, receipts, and held-out tests to separate a persuasive story from evidence that survives contact with reality.

Mission 1 · UAS

Put each card in the right folder.

Unified Address Space (UAS) is a typed library-card system. In a synthetic type-confusion level, typed retrieval found the target 90/90; a flat ranker found it 0/90. A separate local-model test tied, so the broader benefit remains unproven.

Mission 2 · Internal map

See whether a missing fact changes the scratchpad.

In 30 matched Qwen3 0.6B runs, removing a decisive fact moved the final working-state geometry farther from full context than removing an irrelevant fact: a pre-set gap of +0.007617.

Mission 3 · Safe nudge

Try a nudge, then make it earn trust.

Residual-repair v1 improved the target but failed its clean-state gate. An independent v2 gained +0.002557 on held-out cases, beat random control, and kept clean drop at 0.000441. That is a narrow geometry result—not restored memory or general reasoning.

Product × research workflowMain project

Epistemos ↗

My main research-workspace direction: local notes, retrieval, evidence, editing, and bounded AI assistance in one place.

Boundary: it is an AI-assisted project still in development. I can explain the product direction and working surfaces, not every line of its Swift, Rust, and TypeScript code.

Memory × retrievalTwo connected projects

LivingBrain ↗ · Instant Recall ↗

LivingBrain explores decay, reinforcement, contradictions, and reusable skills. Instant Recall explores local search with inspectable ranking. Together they test how a workspace can remember useful information without acting like every stored item is equally current or important.

Boundary: “living brain” is an analogy for software behavior, not a biological model or a claim of human-like cognition.

AI × scienceReproducible comparison

Scientific Reasoning Audit Loops ↗

A small-model experiment comparing direct answers, self-review, and narrow verifier feedback on controlled chemistry, physics, and biology problems.

Boundary: the experiment tests inference-time checking on a synthetic benchmark. It does not show that the model learned science.

Retrieval × provenanceMixed result kept visible

Unified Address Space Reasoning Lab ↗

A typed-address retrieval experiment connecting science observations, defensive-security records, and AI-evaluation notes. One local-model test tied; a narrower metadata-loss ablation improved from 8/24 to 24/24.

Boundary: preserving a useful type label helps when the baseline removes it. That is not proof of a general reasoning improvement.

Data qualityPython learning project

DataSight ↗

A CSV review tool for missing values, outliers, schema risks, and explanations that a person can inspect before deciding what to fix.

Boundary: it flags likely issues; it does not automatically prove that a value is wrong.

Defensive securityAuthorized local lab

Security Operations Lab ↗

Personal-lab packet analysis and localhost service review using Wireshark/TShark, Nmap, Windows records, and written investigation notes.

Boundary: this is self-learning on systems I control, not professional incident-response or penetration-testing experience.
