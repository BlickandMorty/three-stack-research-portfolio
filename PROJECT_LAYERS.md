# Public Project Layers

This is the short technical map of the projects that remain public.

| Project | Input | Mechanism | Check | Saved evidence | Important limit |
| --- | --- | --- | --- | --- | --- |
| Epistemos | Notes, files, sources, user actions | Local workspace, retrieval, editing, bounded AI paths | App builds, development captures, feature-level tests | Code, screenshots, audit records | Still in development; substantial AI assistance |
| Instant Recall | Local document text and titles | BM25, prefix/title scores, trigrams, rank fusion | Deterministic retrieval tests | Source, tests, examples | Ranking is not semantic understanding |
| LivingBrain | Memory records, timestamps, accesses, conflicts | Decay, reinforcement, contradiction handling, tiered retrieval | Rust checks and examples | Source and documented behaviors | Brain language is analogy, not neuroscience |
| Scientific Reasoning Audit Loops | Controlled science questions | Direct response, self-audit, verifier-gated repair | Held-out accuracy, paired transitions, replication | Cases, scratchpads, logits, reports | Synthetic benchmark; verifier has privileged error information |
| Unified Address Space | Typed science, security, and evaluation records | Stable addresses and type-aware retrieval | Exact retrieval and wrong-domain errors | Corpora, reports, local-model outputs | Positive result is narrow; one model test tied |
| DataSight | CSV files | Missingness, outlier, schema, and explanation checks | Unit tests and reviewable output | Reports and source | A flag is not proof of bad data |
| Security Operations Lab | Authorized local packets and services | Wireshark/TShark, Nmap, Windows validation, reporting | Reproduce the capture and compare with local state | Sanitized reports and commands | Personal lab only, not professional incident response |
| Prompt Lab | Goals, evidence, constraints, source material | Prompt templates with falsifiers and approval gates | Review whether required evidence and stopping rules are present | Versioned prompt packs | Prompting does not replace domain review |

Supporting model-internals, formal-math, policy, and graph experiments are private. They may inform future work, but they are not separate public expertise claims.
