# Research Direction

## Public foundation

The current public work has four connected parts:

1. **Workspace:** Epistemos is where notes, evidence, retrieval, and AI assistance meet.
2. **Memory and retrieval:** Instant Recall, LivingBrain, and Unified Address Space test how information is ranked, retained, typed, and revised.
3. **Evaluation:** Scientific Reasoning Audit Loops tests whether checking procedures improve answers without hiding regressions.
4. **Practical work:** DataSight, Security Operations Lab, and Prompt Lab connect the research ideas to data review, defensive investigation, and paid evaluation skills.

## Private backlog

The private research backlog includes model-internals experiments, compression and memory-control ideas, emotional wording versus reasoning, functional valence, formal math, evidence-state probes, policy logic, and graph structure.

These are questions, not credentials. A topic returns to the public profile only after it has:

- one clear question;
- a runnable method;
- saved outputs;
- a failure condition decided in advance;
- a plain explanation;
- an AI-assistance statement;
- enough study that I can defend the technical details.
